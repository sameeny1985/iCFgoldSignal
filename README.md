# atr3 Final Bot (Render Free Web Service)

## تنظیمات Render (پلن رایگان)

| فیلد | مقدار |
|------|------|
| **Service Type** | Web Service |
| **Runtime** | Python 3 |
| **Build Command** | `pip install -r requirements.txt` |
| **Start Command** | `python main.py` |

### Environment Variables

```
TELEGRAM_TOKEN=توکن_ربات
TELEGRAM_CHAT_ID=آیدی_چت
SYMBOL=GC=F
POLL_INTERVAL_SEC=30
CooldownMinutes=3
```

برای طلا حتماً از `GC=F` استفاده کن.
